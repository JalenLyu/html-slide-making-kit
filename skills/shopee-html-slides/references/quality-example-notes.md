## Reusable Rules For This Deck

- Start with background before showing UI operations when the audience needs to understand why the platform exists.
- Use assertion-evidence structure: the title states the takeaway; the screenshot or card proves it.
- Every operation slide should include:
  - `How to do it`: concrete user action.
  - `What it is useful for` / `Why it helps`: platform value.
- Screenshots should be evidence objects, not decoration. If the screenshot is too small to inspect, either crop the source evidence tighter or make the slide about a smaller UI detail.
- For Shopee internal product workflow decks, borrow structure from polished templates but keep Shopee frame, orange rule, bag icon, footer, and business typography.
- Avoid a report-table feel for workflow education. Use process chains, state cards, explanation cards, and checklists.
- When PPTX is a static sharing artifact, render it from the canonical HTML to avoid content drift.
